# Development documentation

Test evidence, historical references and proposals live here. This entire folder stays outside the Obsidian mirror and does not define current runtime configuration.

- [Experiments](experiments/README.md): recorded tests, measurements and investigations.
- [History](history/README.md): saved baselines, retired guides and original audits.
- [Ideas](ideas/README.md): discussion-only proposals requiring separate implementation authorization.

Use [Active documentation](../README.md#active--mirrored-into-obsidian) for current operation and maintenance. When a feature changes, update its Active guide and record the supporting test results here. Preserve dates, tested configurations and limitations so older results are not mistaken for new verification.
